# SIMRS — Rumah Sakit Dunia Indah

Website prototype **Sistem Informasi Manajemen Rumah Sakit (SIMRS)** menggunakan Next.js.

## Modul

* **EMR** — Electronic Medical Record
* **Inpatient** — Manajemen Rawat Inap
* **Billing & Insurance** — Billing dan Asuransi

## Teknologi

* Next.js
* React
* TypeScript
* Tailwind CSS

## Menjalankan Project

### 1. Clone Project

Clone digunakan untuk **mengambil salinan project dari GitHub ke komputer**.

Buka terminal/Command Prompt, lalu jalankan:

```bash
git clone URL_REPOSITORY
```

Contoh:

```bash
git clone https://github.com/username/nama-project.git
```

Kemudian masuk ke folder project:

```bash
cd nama-project
```

### 2. Install Dependencies

Jalankan:

```bash
npm install
```

Perintah ini akan menginstall semua kebutuhan project.

### 3. Jalankan Project

```bash
npm run dev
```

Kemudian buka browser dan akses:

```text
http://localhost:3000
```

## Tujuan Project

Project ini berfokus pada **UI/UX SIMRS** berdasarkan kebutuhan dan SOP rumah sakit.

Saat ini pengembangan difokuskan pada **frontend**, belum menggunakan backend dan database.
